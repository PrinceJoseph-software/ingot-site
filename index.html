Ingot is a browser extension for Chrome, Edge and Firefox. Hover any element to see its spacing, fonts and colours. Run an assay and Ingot refines the whole page into a design system: merged colours named by role, a detected type scale, the spacing grid, radii and shadows, each with a grade showing how confident it is.
